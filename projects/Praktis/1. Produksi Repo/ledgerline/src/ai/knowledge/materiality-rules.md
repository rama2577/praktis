# Materiality Rules — Versi 1.0

## Default Thresholds
| Kategori | Threshold |
|---|---|
| Overall materiality | 1-2% × revenue |
| Performance materiality | 75% × overall |
| Trivial threshold | 5% × overall |

## Specific Thresholds
| Item | Threshold |
|---|---|
| Aset tetap capitalization | Rp 2.000.000 |
| Single journal entry | Rp 10.000.000 |
| Rounding difference | Rp 100 |
| Bank recon timing diff | Rp 500.000 |
| Inventory adjustment | Rp 5.000.000 |
| Owner drawing | ANY amount |
| Related party | Rp 5.000.000 |
| Loan proceeds | ANY amount |

## Waiver Rules
Auto-approve boleh jika:
1. Pattern ≥6 bulan berturut tanpa adjustment
2. Vendor/customer recurring & verified
3. Entry allocation/accrual deterministic
4. Amount berbeda <10% dari bulan lalu

TIDAK BOLEH auto-approve:
1. Prive/owner drawing
2. Related party
3. New vendor/customer
4. Capital expenditure
5. Tax-related entries
6. Suspense account entries
