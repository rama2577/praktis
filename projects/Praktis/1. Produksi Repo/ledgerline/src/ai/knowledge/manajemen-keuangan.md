## 1. Tujuan Manajemen Keuangan
Tujuan utama: **memaksimalkan nilai perusahaan / kesejahteraan pemegang saham** (bukan sekadar
laba jangka pendek). Tiga keputusan pokok: **investasi** (capital budgeting), **pendanaan**
(struktur modal utang vs ekuitas), **dividen**. Perhatikan agency problem & tata kelola (GCG/OJK).

## 2. Nilai Waktu Uang (Time Value of Money)
r = tingkat bunga/diskonto per periode; n = jumlah periode.
FV tunggal = PV × (1 + r)^n
PV tunggal = FV / (1 + r)^n
FV Anuitas biasa = PMT × [((1 + r)^n − 1) / r]
PV Anuitas biasa = PMT × [(1 − (1 + r)^-n) / r]
Annuity due      = (nilai anuitas biasa) × (1 + r)
Perpetuity        = PMT / r
Growing Perpetuity = PMT₁ / (r − g)   ; syarat r > g
EAR (Effective Annual Rate) = (1 + i/m)^m − 1   ; m = frekuensi compounding/tahun
Contoh: Menabung Rp10 jt/tahun, 5 tahun, r=8% (ordinary annuity):
FV = 10jt × [((1,08)^5 − 1)/0,08] = 10jt × 5,8666 = **Rp58,67 jt**.

## 3. Analisis Rasio Keuangan
Gunakan **rata-rata** untuk pos neraca (persediaan, piutang) dalam rasio aktivitas; setahun = 365 hari.
**Likuiditas:**
Current Ratio = Aset Lancar / Liabilitas Lancar
Quick Ratio   = (Aset Lancar − Persediaan − Beban dibayar dimuka) / Liabilitas Lancar
Cash Ratio    = (Kas + Setara Kas) / Liabilitas Lancar
**Solvabilitas/Leverage:**
Debt Ratio        = Total Liabilitas / Total Aset
DER               = Total Liabilitas / Total Ekuitas
Equity Multiplier = Total Aset / Total Ekuitas
Interest Coverage (TIE) = EBIT / Beban Bunga
DSCR              = EBITDA / (Pokok + Bunga)
**Aktivitas/Efisiensi:**
Inventory Turnover = HPP / Rata-rata Persediaan  ;  DIO = 365 / Inventory Turnover
Receivable Turnover = Penjualan Kredit / Rata-rata Piutang  ;  DSO = 365 / Receivable Turnover
Payable Turnover   = HPP (atau Pembelian) / Rata-rata Utang Usaha  ;  DPO = 365 / Payable Turnover
Total Asset Turnover = Penjualan / Rata-rata Total Aset
Cash Conversion Cycle (CCC) = DIO + DSO − DPO
**Profitabilitas:**
Gross Profit Margin     = Laba Kotor / Penjualan
Operating Profit Margin = EBIT / Penjualan
Net Profit Margin       = Laba Bersih / Penjualan
ROA  = Laba Bersih / Rata-rata Total Aset
ROE  = Laba Bersih / Rata-rata Ekuitas
ROIC = NOPAT / Invested Capital  ; NOPAT = EBIT × (1 − pajak) ; Invested Capital = Utang berbunga + Ekuitas
**Rasio Pasar:**
EPS = (Laba Bersih − Dividen Preferen) / Jumlah Saham Beredar
PER = Harga Saham / EPS
PBV = Harga Saham / Nilai Buku per Saham  ; BV per Share = Total Ekuitas / Saham Beredar
Dividend Yield        = DPS / Harga Saham
Dividend Payout Ratio = DPS / EPS
**DuPont Analysis:**
ROE = Net Profit Margin × Total Asset Turnover × Equity Multiplier
= (Laba Bersih/Penjualan) × (Penjualan/Aset) × (Aset/Ekuitas)
= Profitabilitas × Efisiensi Aset × Leverage
5-langkah: ROE = (LB/EBT) × (EBT/EBIT) × (EBIT/Penjualan) × (Penjualan/Aset) × (Aset/Ekuitas)
Manfaat: tahu apakah ROE tinggi berasal dari margin, efisiensi aset, atau leverage (risiko).

## 4. Manajemen Modal Kerja
Working Capital = Aset Lancar − Liabilitas Lancar
Net Working Capital operasi = (Piutang + Persediaan) − Utang Usaha
- **Kas** — jaga saldo optimal (Baumol/Miller-Orr); percepat penerimaan, tunda pengeluaran wajar.
- **Piutang** — kebijakan kredit (mis. "2/10 net 30"), 5C (Character, Capacity, Capital, Collateral, Condition), aging, tekan DSO.
- **Persediaan** — EOQ, reorder point, safety stock, JIT.
EOQ = √(2 × D × S / H)   ; D=permintaan tahunan, S=biaya pesan/order, H=biaya simpan/unit/tahun
- **Utang Usaha** — manfaatkan tempo tanpa merusak hubungan pemasok; evaluasi diskon tunai vs biaya kesempatan.

## 5. Penganggaran Modal (Capital Budgeting)
Cₜ = arus kas periode t; C₀ = investasi awal; r = discount rate (biasanya WACC).
NPV = Σ [Cₜ / (1 + r)^t] − C₀        → NPV>0 terima; pilih NPV tertinggi
IRR : r sehingga NPV = 0             → IRR > hurdle rate terima ; MIRR mengatasi asumsi reinvestasi
Payback Period = waktu balik modal (arus nominal) → abaikan TVM & arus setelah payback
Discounted Payback = payback dengan arus terdiskon
Profitability Index (PI) = PV Arus Masuk / Investasi Awal = 1 + (NPV/C₀)  → PI>1 terima
Kaidah: **NPV kriteria terbaik** (mengukur tambahan nilai absolut). IRR bisa menyesatkan pada
arus kas non-konvensional/skala berbeda — utamakan NPV bila konflik.
Contoh: Investasi Rp100 jt, arus Rp40 jt/tahun 3 tahun, r=10%.
PV = 40/1,1 + 40/1,21 + 40/1,331 = 99,47 → **NPV = −Rp0,53 jt** (tolak). IRR ≈ 9,7%.
