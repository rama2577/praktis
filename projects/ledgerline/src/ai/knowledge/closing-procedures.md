# Monthly Closing Procedures — Versi 1.0

## Pre-Closing (H+1 to H+3)
1. [ ] Bank statement diterima
2. [ ] Sales & expense records diinput
3. [ ] Payroll data lengkap
4. [ ] Bank reconciliation
5. [ ] Investigasi selisih > trivial

## Closing Entries (H+3 to H+5)
6. [ ] Penyusutan aset tetap
7. [ ] Amortisasi aset tidak berwujud
8. [ ] Prepaid expense allocation
9. [ ] Accrued expenses
10. [ ] Stock opname & adjustment
11. [ ] NRV assessment
12. [ ] Revenue recognition (PSAK 72)
13. [ ] Lease assessment (PSAK 73)

## Post-Closing (H+5 to H+7)
14. [ ] Trial balance
15. [ ] Laporan Laba Rugi
16. [ ] Neraca
17. [ ] Laporan Perubahan Ekuitas
18. [ ] Laporan Arus Kas
19. [ ] PPN reconciliation → SPT
20. [ ] PPh computation
21. [ ] Junior → Senior → Tax review
22. [ ] Partner approval
23. [ ] Archive & period lock

## SLA
| Stage | Target |
|---|---|
| Data completeness | H+2 |
| Bank reconciliation | H+2 |
| Closing entries | H+3 |
| Financial statements | H+5 |
| Tax computation | H+5 |
| Review & approval | H+7 |
